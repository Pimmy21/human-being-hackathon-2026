# Purrpose Handoff Baseline

Date: 23 October 2026.

## Confirmed by Shiyuan

- Use Purrpose as the main direction for the detailed handoff.
- Help organizations of all sizes have a fair chance to be seen through evidence.
- Make the case's request, supporting evidence, funding information and unknowns the main experience.
- Treat later updates as the final layer, not the product's central promise.
- Prepare enough guidance for the team to continue during her absence; escalate genuine product-boundary and definition-of-done decisions.

## Reversible implementation defaults proposed in the guide

- Start with one curated cat medical fundraiser and a small inspectable pipeline.
- Python API/backend, React/TypeScript frontend and official H-MEM adapter are suggested, not already implemented.
- Use synthetic fixtures openly for engineering while permitted real-case evidence is researched.
- Keep model generation bounded and separate from deterministic evidence and funding rules.

## Not yet decided or completed

- Named task owners, real case selection, data permissions and final track/submission details.
- Complete frontend/backend, case-level integrations and fresh-clone startup.
- A successful Nightshift application provider call.
- New cloud tables/resources, paid services, public hosting or actual donor accounts.

The antenna proposal remains available in `ideas/`. This handoff does not authorize building both products or claiming final hackathon compliance.
