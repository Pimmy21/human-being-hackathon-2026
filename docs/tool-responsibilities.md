# Tool Responsibilities

These are proposed roles for either idea, not claims that the final application is integrated.

| Tool | Role | Evidence we should show |
|---|---|---|
| Meterless H-MEM | Store sourced information and recall it when the agent needs it | A saved record, a later retrieval and an answer or comparison that actually uses it |
| Meterless Nightshift | Application AI provider route | A successful application request and response, separately from direct NVIDIA requests |
| Zetaris | Query registered structured sources for comparison | Actual queries, returned records and source provenance |
| NVIDIA | Hosted model inference for reading or explaining supplied material | Model response, citations, limitations and returned usage |
| Cursor, ChatGPT and Codex | Development, research assistance, coding, review and tests | Changes and tests; these tools do not themselves establish that evidence is true |
| Design tools | Improve the interface and visual communication | A usable interface, clear uncertainty states and accurate visuals |

Do not claim that a library was integrated only because it was installed. Clearly label real data, snapshots, synthetic examples and untested plans.
