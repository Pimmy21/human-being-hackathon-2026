How the pieces connect

The Purrpose workflow, node by node.

A request comes in on the left. The orchestrator asks the chat model what the person wants, then sends three agents to work: the Evidence Collector gathers evidence, the Evidence Evaluator checks every finding, and the Dispute Resolver investigates conflicts. Plain code then runs the six checks and decides which answer to give. Select any node to see what it is, or run an example to watch a request move through the system.
