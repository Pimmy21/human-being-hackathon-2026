# Full product specification

This folder retains the detailed product requirements, examples, policy reference and acceptance scope agreed during product design. It is a target specification, including substantial future work. It is not a claim that every requirement is implemented in the hackathon prototype.

For actual shipped capabilities and tool setup, start with the [repository README](../../README.md), [Architecture](../ARCHITECTURE.md) and [Validation](../VALIDATION.md).

- `HUMAN_GUIDE.md`: plain-language product rules.
- `FULL_GUIDANCE.md`: detailed developer specification.
- `EXAMPLES.md` and `ACCEPTANCE_CASES.md`: expected behaviors and future acceptance cases.
- `RULE_MAP.md`, `policy.example.json`, `DOCUMENT_CHECKS.json`: rule references and illustrative policy data.
- `OPEN_DECISIONS.md`, `BUILD_PLAN.md`, `REVISION_NOTES.md`: design decisions and implementation planning context.

Ontario is the prototype's reference profile. Adding another region requires appropriate sources, permissions and policy verification, not only changing a city label.
