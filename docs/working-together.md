# Working Together

## Our shared project home

Use this repository for the latest agreed documents and, once selected, the project code. Use issues for tasks and open questions. Use pull requests for changes teammates should review.

Keep both ideas available while discussing them. Record the final choice, reason and smallest demo scope in this folder after the team agrees.

## Mentor feedback

Record the date, question, advice and team decision. Distinguish a mentor suggestion from an agreed requirement. Never put private chat transcripts here without permission.

## Before uploading

- Check files for keys, passwords, access tokens and private data. Ignore rules alone do not make a repository safe.
- Keep `.env.local`, virtual environments, model weights, full chat exports and raw private documents outside version control.
- Commit only material we have permission to share. Cite or link to published papers rather than uploading copies by default.
- Store final approved documents in the repository. Link to large demo videos and datasets.
- Invite teammates using their GitHub usernames; do not share account passwords.

Start with a private repository while preparing the project. Confirm the hackathon's submission visibility rules before final submission. We have not chosen a software license yet.
