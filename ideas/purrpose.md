# Purrpose

Working name · Proposal for team and mentor discussion

## What we want to do

Purrpose gives animal rescue organizations of all sizes a fair chance to be seen. It helps donors look beyond social media popularity and understand a rescue's needs through evidence.

A rescue with fewer followers should still have a chance to receive support. Donors should be able to see what their help could do and what information is still missing.

## How it works

A donor shares a fundraiser or asks to find a rescue to support. Purrpose brings together available information and helps answer:

- What help is being requested?
- What evidence supports the request?
- How much money is needed, and how much has already been raised?
- What is still unclear or needs checking?

After support, Purrpose can review updates about how the money was used and what happened to the animal. These updates become evidence for future decisions. Organization-level spending does not tell us where an individual donor's exact contribution went.

## Our first demo

We will start with one fundraiser for a cat's medical care. The donor can review the request, see the supporting information and ask follow-up questions.

The demo should feel warm and easy to use. Every finding should link back to its source. If information is missing, Purrpose should say so rather than guess. A registration record alone does not prove that a particular fundraiser is genuine or currently needs money.

## Where the tools fit

- **Zetaris:** bring registered structured information from different sources into one query layer.
- **Meterless H-MEM:** remember evidence and earlier findings so the agent can use them later.
- **NVIDIA models:** help read and explain the information.
- **Nightshift:** a planned AI provider connection that still needs to be completed.
- **Cursor, ChatGPT and Codex:** help us build, test and improve the product.
- **Design tools and skills:** help us create a clear, polished interface.
