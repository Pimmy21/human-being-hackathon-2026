# Purrpose orange kitten

Original pixel-art mascot for Purrpose. The animated GIF blinks and swishes its tail in a 2.4-second loop. It contains no third-party artwork.

- `purrpose-ginger.gif`: README animation, 14 stored frames (16 source frames; repeated holds are combined).
- `purrpose-ginger.svg`: editable static vector version.
- `purrpose-ginger.png`: static transparent image.
- `build_mascot.py`: source generator. Run with Python and Pillow to regenerate the assets.

The application does not need Pillow; it is only used to build these design assets.
