# Purrpose kitten

`purrpose-kitten-blink-v2.gif` is the selected hand-painted orange kitten mascot on a grassy patch. Its body and background remain fixed; only the eyes move in a gentle blink approximately every 5 seconds.

Illustration and eyelid frames were generated with OpenAI image generation. The eye regions were assembled over a single fixed base image to prevent frame-to-frame body or background jitter. The looping GIF uses a white matte and a shared palette for README compatibility. No external stock artwork is included.

The loop holds one unchanged open-eyed frame for 4.8 seconds and shows a closed-eye frame for 180 ms. There are no intermediate morphing frames. Every pixel outside the eye patches is identical. The versioned filename avoids stale image-cache reuse.
