This explicit check sends one fixed read-only SQL query to your explicitly configured Zetaris. AWS mode queries Toronto Cat Rescue; local REST mode queries Guelph Humane Society. The result identifies the organization actually queried. No model calls, payment or automatic retries.

Historical identity is background evidence, not proof of current registration, current medical need, funding or trust. A source failure does not mean fraud. Results cannot qualify Lucy.

Local query example and setup

SELECT fact.BN, fact.`Legal Name`, fact.City, fact.Province FROM CRA_CHARITIES_2024.ontario_animal_identity LATERAL VIEW explode(result.records) AS fact WHERE fact.BN = '119236305RR0001'

AWS mode instead queries the existing DONATION_FEASIBILITY_20261022.tcr_identity table. Neither mode accepts user SQL. The source table must already exist. Setup SQL is not executed by this page. The backend accepts no charity number, SQL or URL from chat or this form.
